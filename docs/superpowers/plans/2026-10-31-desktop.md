# Windows masaüstü dönüşümü uygulama planı

**Amaç:** Mevcut Ders Defteri arayüzünü tarayıcı/terminal gerektirmeden açılan Windows exe uygulaması olarak teslim etmek.
**Mimari:** React arayüzü paketlenmiş dosyalardan Electron penceresinde çalışır. İzole preload yalnızca yükle/kaydet işlevlerini sunar. Ana süreç doğrulanmış veriyi kullanıcı veri klasöründe atomik olarak saklar. Tek uygulama örneği çalışır. Tarayıcıdaki eski veriler mevcut JSON yedek akışıyla taşınır.
**Teknolojiler:** Electron, TypeScript, mevcut React/Vite; Windows NSIS kurulum paketi ve açılabilir klasör paketi.

- [x] Kalıcı dosya deposu: gerçek geçici dizinde ilk açılış, yeniden açma, bozuk dosya koruması, geçersiz yazım ve önceki sürüm yedeği testlerini yaz; eksik davranışları doğrula; doğrulamalı ve atomik depoyu uygula.
- [x] Masaüstü kabuğu: sandbox/contextIsolation, sınırlı IPC, aynı dosyaya kilitli gezinme, tek örnek, hata diyalogları; arayüz storage adaptörünü bağla. Dosya tabanlı Vite çıktısı ve yerel fontlar kullan.
- [x] Paket: simge, ürün adı, kurulum/masaüstü kısayolu; Baslat.cmd hazır exe çalıştırsın. Eski tarayıcıdan JSON taşıma talimatını belgele.
- [x] Doğrulama: tüm birim testleri, web regresyonları, gerçek Electron aç/kaydet/kapat/yeniden aç testi, pencere görüntüsü ve Windows paket üretimi. Paket kullanıcı verisi içermesin.

Varsayımlar: Windows x64; otomatik güncelleme ve bulut yok; veriler %APPDATA%/DersDefteri içinde; imza sertifikası yok. Eski tarayıcı kayıtları silinmez.
