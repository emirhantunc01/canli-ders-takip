# Android telefon sürümü uygulama planı

**Amaç:** Ders Defteri'ni yalnızca Android telefonda, çevrimdışı kullanmak için kurulabilir APK üretmek.
**Mimari:** Mevcut React/TypeScript arayüzü APK içindeki yerel dosyalardan güvenli HTTPS varlık adresinde Android WebView'da açılır. Uygulama Java köprüsüyle özel SQLite dosyasında tek işlemle doğrulanmış kayıt ve önceki sürümü saklar. Yedek dışa aktarma Android belge oluşturma, içe aktarma mevcut doğrulama/onay akışını kullanır. İnternet/senkronizasyon hesabı gerekmez.
**Teknolojiler:** Android Java 17, Gradle/AGP, AndroidX WebKit, React/Vite. Android 8+; telefon odaklı dikey ekran.

- [x] Native veri ve belge köprüsü: eksik köprü, yanlış veri, kaydet/yeniden aç ve v1/v2 yedek testleri. SQLite commit başarısız olursa UI'ya hata dön; boş veriyle üzerine yazma.
- [x] Mobil ekran: görünür alt gezinme, 44+px dokunma hedefleri, tek sütun hesap kartları, klavye/diyalog uyumu ve liste varsayılanı; hafta/ay korunur.
- [x] Android kabuğu: yalnızca APK varlıklarını yükle, harici gezinme/izinleri engelle, WebView'a genel dosya erişimi verme. Sistem belge seçicisiyle JSON al/ver. Android geri tuşu açık diyaloğu/menüyü kapatsın.
- [x] APK: sabit paket kimliği ve yerel imzalama anahtarı; imzalama dosyaları/kullanıcı yedekleri repoya girmez. APK ve SHA256 üret.
- [x] Doğrulama: mevcut birim/web testleri, native SQLite enstrümantasyon testleri, Android emülatörde açılış/kayıt/yeniden açılış/yedek ekranı; 390px UI kontrolü. Hazır APK teslimi ve masaüstünden JSON aktarımı açıklaması.

Varsayımlar: yalnızca Android; Play Store yayını yok; bulut/eşitleme yok. Bilgisayardaki kullanıcı kayıtları APK içine gömülmez. Uygulama kaldırılırsa cihazdaki özel kayıtlar silinir; kullanıcı JSON yedeği alır. Mevcut Windows sürümü çalışmaya devam eder.
